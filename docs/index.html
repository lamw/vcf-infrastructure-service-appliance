Infrastructure services for VCF Lab & POC

Simplify your VCF 9 Lab Experience

The VCF Infrastructure Services (VIS) Appliance is an Ubuntu-based virtual appliance that provides key infrastructure services for accelerating VMware Cloud Foundation (VCF) 9.1 lab and proof-of-concept deployments. VIS includes a user-friendly web management interface that allows users to quickly get started without requiring in-depth knowledge of the underlying services.

Software Depot

Stages VCF/VVF binaries, async patches, and ESX patches through manual upload or VCF Download Tool activation-code workflows.

HTTP/HTTPS VCFDT Shared TLS
  • Supports HTTP or HTTPS with optional basic authentication.
  • Provides repository browsing, folder management, delete confirmation, and drag-and-drop uploads.
  • Installs VCF Download Tool from a user-provided tarball and validates activation-code workflows.
  • Runs long VCF/VVF and ESX patch downloads asynchronously with status, cancellation, and logs.
